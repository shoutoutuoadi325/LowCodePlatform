# 功能特性说明

## 平台功能概览

曦源 IoT 低代码平台是一个面向教学楼的智能物联网管理系统，提供设备管理、场景编排和可视化监控等核心功能。

## 核心功能

### 1. 设备管理

#### 1.1 设备类型支持

平台支持 15 种常见教学楼设备类型：

| 设备类型 | 英文标识 | 功能描述 | 支持操作 |
|---------|---------|---------|---------|
| 灯光 | LIGHT | 教室照明控制 | 开/关、亮度调节、颜色设置 |
| 空调 | HVAC | 温度调节系统 | 开/关、温度设置、模式切换、风速调节 |
| 温度传感器 | TEMPERATURE_SENSOR | 环境温度监测 | 读取温度值 |
| 湿度传感器 | HUMIDITY_SENSOR | 环境湿度监测 | 读取湿度值 |
| 人体感应 | MOTION_SENSOR | 人员移动检测 | 检测是否有人 |
| 门锁 | DOOR_LOCK | 门禁控制 | 上锁/解锁 |
| 窗户 | WINDOW | 窗户控制 | 开/关、位置调节 |
| 窗帘 | CURTAIN | 窗帘控制 | 开/关、位置调节 |
| 投影仪 | PROJECTOR | 教学投影设备 | 开/关、输入源切换 |
| 投影幕 | SCREEN | 投影幕布控制 | 升起/放下 |
| 风扇 | FAN | 通风设备 | 开/关、风速调节 |
| 空气质量传感器 | AIR_QUALITY_SENSOR | 空气质量监测 | PM2.5、CO2 浓度读取 |
| 摄像头 | CAMERA | 视频监控 | 开/关、录制控制 |
| 扬声器 | SPEAKER | 音频播放 | 开/关、音量调节 |
| 电源开关 | POWER_SWITCH | 电源控制 | 开/关 |

#### 1.2 设备管理功能

- **设备注册**：添加新设备到系统
- **设备配置**：设置设备位置、属性等信息
- **设备控制**：远程控制设备状态
- **状态查询**：实时获取设备状态
- **设备搜索**：按位置、类型、房间等条件查询
- **设备删除**：移除不再使用的设备

#### 1.3 位置管理

设备支持多级位置管理：

```
教学楼 (building)
  └── 楼层 (floor)
      └── 房间 (room)
          └── 具体位置 (location)
```

示例：
- 教学楼：理科楼
- 楼层：3F
- 房间：301教室
- 位置：前排左侧

### 2. 场景编排

#### 2.1 场景组成

一个完整的场景包含：

**触发器 (Triggers)**
- 定义场景何时执行
- 支持多个触发器（满足任一即可）
- 触发器类型：
  - 手动触发：用户主动执行
  - 定时触发：指定时间自动执行
  - 设备状态触发：设备状态改变时触发
  - 传感器触发：传感器数值满足条件时触发
  - 时间触发：基于时间规则
  - 位置触发：基于地理位置（预留）

**动作 (Actions)**
- 定义执行什么操作
- 支持多个动作按顺序执行
- 每个动作包含：
  - 目标设备
  - 操作类型（开/关/设置状态）
  - 操作参数
  - 延迟时间（与上一个动作的间隔）
  - 执行顺序

#### 2.2 场景设计器

**可视化编排**
- 图形化界面设计场景
- 拖拽式操作，无需编程
- 实时预览场景流程

**触发器配置**
- 选择触发类型
- 配置触发条件
- 支持复杂条件表达式

**动作流程设计**
- 添加/删除动作
- 调整动作顺序
- 设置动作参数
- 配置延迟时间

#### 2.3 场景管理

- **场景创建**：通过设计器创建新场景
- **场景编辑**：修改现有场景配置
- **场景启用/禁用**：控制场景是否可执行
- **场景执行**：手动或自动触发场景
- **场景删除**：删除不需要的场景
- **场景复制**：基于现有场景快速创建

### 3. 可视化监控

#### 3.1 仪表板

**统计信息**
- 设备总数
- 在线设备数
- 场景总数
- 活跃场景数

**快速访问**
- 最近添加的设备
- 常用场景快捷执行
- 实时设备状态

#### 3.2 设备列表

**多维度展示**
- 表格视图：详细信息列表

**状态指示**

- 最后更新时间

### 4. 模拟设备系统

#### 4.1 设备模拟器

为便于开发和测试，平台内置设备模拟器：

- **状态模拟**：模拟设备各种状态
- **行为模拟**：模拟设备响应
- **数据生成**：模拟传感器数据
- **故障模拟**：模拟设备异常

#### 4.2 模拟器特性

- 支持所有设备类型
- 可配置初始状态
- 实时状态更新
- 命令响应模拟

#### 4.3 真实设备集成

预留 Home Assistant 集成接口：

```java
public interface DeviceAdapter {
    boolean connect(String deviceId);
    boolean disconnect(String deviceId);
    Map<String, Object> getState(String deviceId);
    boolean control(String deviceId, String action, Map params);
}
```
