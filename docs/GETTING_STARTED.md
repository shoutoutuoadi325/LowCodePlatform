## 环境准备

### 开发环境要求

- **Java 17+**: 运行后端服务
- **Node.js 18+**: 运行前端应用
- **Maven 3.6+**: 构建后端项目
- **Git**: 克隆项目

### 可选工具

- **Docker & Docker Compose**: 容器化部署
- **Postman**: API 测试
- **VSCode** 或 **IntelliJ IDEA**: 代码编辑

## 运行平台

### 方式一：本地开发模式（推荐）

#### 1. 克隆项目

```bash
git clone https://github.com/shoutoutuoadi325/LowCodePlatform.git
cd LowCodePlatform
```

#### 2. 启动后端服务

**启动设备管理服务：**

```bash
cd backend/device-service
mvn spring-boot:run
```

服务将在 `http://localhost:8081` 启动。

打开新终端，**启动场景编排服务：**

```bash
cd backend/scene-service
mvn spring-boot:run
```

服务将在 `http://localhost:8082` 启动。

#### 3. 启动前端应用

打开新终端：

```bash
cd frontend
npm install
npm run serve
```

前端将在 `http://localhost:8080` 启动。

#### 4. 访问平台

在浏览器中打开 `http://localhost:8080`，即可看到平台界面。

### 方式二：Docker 部署

```bash
# 在项目根目录执行
docker-compose up -d
```

等待容器启动完成后，访问 `http://localhost:8080`。

查看日志：
```bash
docker-compose logs -f
```

停止服务：
```bash
docker-compose down
```

## 基本操作

### 1. 设备管理

#### 添加设备

1. 点击顶部菜单的"设备管理"
2. 点击右上角的"添加设备"按钮
3. 填写设备信息：
   - 设备名称：如"教室前排灯光"
   - 设备类型：选择合适的类型（灯光、空调等）
   - 教学楼：如"理科楼"
   - 楼层：如"3F"
   - 房间：如"301教室"
   - 位置描述：如"前排左侧"
   - 状态：选择"在线"或"离线"
4. 点击"确定"保存

#### 控制设备

1. 在设备列表中找到要控制的设备
2. 点击"控制"按钮
3. 选择操作：
   - **开启**：打开设备
   - **关闭**：关闭设备
   - **设置状态**：自定义设备参数
4. 点击"执行"

#### 查看设备状态

1. 在设备列表中点击"查看状态"按钮
2. 查看设备当前的所有状态信息

### 2. 场景管理

#### 创建场景

1. 点击顶部菜单的"场景编排"
2. 填写场景基本信息：
   - 场景名称：如"上课模式"
   - 场景描述：描述场景的用途
   - 状态：启用或禁用

3. **配置触发器**（可选）：
   - 点击"触发器"标签页
   - 点击"添加触发器"
   - 选择触发类型：
     - 手动触发：需要手动执行
     - 定时触发：指定时间自动执行
     - 设备状态：设备状态改变时触发
     - 传感器数值：传感器数值满足条件时触发

4. **配置动作流程**：
   - 点击"动作流程"标签页
   - 点击"添加动作"
   - 为每个动作配置：
     - 选择设备
     - 选择操作（打开/关闭/设置状态）
     - 设置参数（如果需要）
     - 设置延迟时间（秒）
   - 使用"上移"/"下移"按钮调整动作顺序

5. 点击"保存场景"

#### 执行场景

方式一：从仪表板执行
1. 在仪表板的"快速场景"区域
2. 点击场景按钮直接执行

方式二：从场景管理执行
1. 点击"场景管理"菜单
2. 找到要执行的场景
3. 点击"执行"按钮

### 3. 仪表板

仪表板提供平台的整体概览：

- **统计卡片**：显示设备和场景的统计信息
- **最近设备**：查看最近添加的设备
- **快速场景**：一键执行常用场景

## 场景编排示例

### 示例1：上课模式

**目标**：准备教室上课环境

**步骤**：

1. 创建场景"上课模式"
2. 添加手动触发器
3. 添加以下动作（按顺序）：
   - 打开教室灯光（延迟0秒）
   - 打开投影仪（延迟2秒）
   - 放下投影幕（延迟3秒）
   - 关闭窗帘（延迟4秒）
   - 设置空调温度为22度（延迟5秒）
4. 保存并启用场景

### 示例2：下课模式

**目标**：关闭教室设备

**步骤**：

1. 创建场景"下课模式"
2. 添加手动触发器
3. 添加以下动作：
   - 关闭投影仪
   - 升起投影幕（延迟2秒）
   - 打开窗帘（延迟3秒）
   - 关闭空调（延迟4秒）
   - 关闭部分灯光（延迟5秒）
4. 保存并启用场景

### 示例3：节能模式（传感器触发）

**目标**：无人时自动关闭设备

**步骤**：

1. 创建场景"节能模式"
2. 添加传感器触发器：
   - 类型：传感器数值
   - 设备：人体感应传感器
   - 条件：motion == false（10分钟无人）
3. 添加以下动作：
   - 关闭灯光
   - 关闭空调
   - 关闭投影仪
4. 保存并启用场景

### 示例4：温度控制

**目标**：根据温度自动调节空调

**步骤**：

1. 创建场景"温度控制"
2. 添加传感器触发器：
   - 类型：传感器数值
   - 设备：温度传感器
   - 条件：temperature > 26
3. 添加动作：
   - 设备：空调
   - 操作：设置状态
   - 参数：`{"temperature": 24, "mode": "cool"}`
4. 保存并启用场景

## 常见问题

### Q1: 启动后端服务时出现端口冲突

**A**: 检查端口 8081 和 8082 是否被占用：

```bash
# Windows
netstat -ano | findstr "8081"
netstat -ano | findstr "8082"

# Linux/Mac
lsof -i :8081
lsof -i :8082
```

如果被占用，可以修改 `application.yml` 中的端口配置。

### Q2: 前端无法连接后端服务

**A**: 检查以下几点：
1. 确保后端服务已启动
2. 检查防火墙设置
3. 查看浏览器控制台的错误信息
4. 确认 `vue.config.js` 中的代理配置正确

### Q3: Maven 构建失败

**A**: 常见原因：
1. Java 版本不对（需要 Java 17+）
2. Maven 仓库无法访问（配置国内镜像）
3. 网络问题（重试或使用 VPN）

配置 Maven 国内镜像：
```xml
<!-- ~/.m2/settings.xml -->
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### Q4: npm install 失败

**A**: 使用国内镜像：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q5: 场景执行没有反应

**A**: 检查以下几点：
1. 场景状态是否为"启用"
2. 场景中的设备是否存在且在线
3. 查看后端服务日志
4. 确认设备ID正确

### Q6: 如何重置数据库

**A**: 本平台使用 H2 内存数据库，重启服务即可重置。

如需持久化数据，修改 `application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:h2:file:./data/devicedb  # 文件数据库
```

### Q7: Docker 容器启动失败

**A**: 查看日志：

```bash
docker-compose logs device-service
docker-compose logs scene-service
docker-compose logs frontend
```

常见问题：
- 内存不足：增加 Docker 内存限制
- 端口冲突：修改 docker-compose.yml 端口映射
