# 智能设备管理平台演示指南

## 演示前准备工作

### 1. 环境检查
- 确保 Docker 和 Docker Compose 已安装
- 确保 Node.js 和 npm/pnpm 已安装
- 检查端口占用情况（8080, 8081, 8082, 1883）

### 2. 启动系统
```bash
# 进入项目根目录
cd LowCodePlatform

# 启动后端服务（Docker）
docker-compose up -d

# 启动前端服务
cd frontend
npm run serve
# 或者
pnpm run serve
```

### 3. 验证服务状态
- 前端访问地址：http://localhost:8080
- 后端设备服务：http://localhost:8081
- 后端场景服务：http://localhost:8082
- MQTT 服务：localhost:1883

## 常见问题处理

### 1. 服务启动问题
**问题**：Docker 服务启动失败
**解决**：
```bash
# 检查端口占用
netstat -an | findstr :8081
netstat -an | findstr :8082
netstat -an | findstr :1883

# 重新启动服务
docker-compose down
docker-compose up -d
```

### 2. 前端访问问题
**问题**：前端页面无法访问
**解决**：
```bash
# 检查前端服务状态
cd frontend
npm run serve

# 检查端口占用
netstat -an | findstr :8080
```

### 3. 数据显示问题
**问题**：页面数据不显示
**解决**：
- 检查浏览器控制台错误信息
- 确认 API 服务正常运行
- 刷新页面重新加载数据

### 4. 设备控制问题
**问题**：设备控制无响应
**解决**：
- 检查 MQTT 服务状态
- 确认设备模拟器运行状态
- 查看系统日志排查问题

### 5. 性能问题
**问题**：系统响应缓慢
**解决**：
- 检查系统资源使用情况
- 重启相关服务
- 清理浏览器缓存
