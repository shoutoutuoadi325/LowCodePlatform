# 智能设备管理平台 - 前端测试操作指南

## 📋 项目概述

智能设备管理平台是一个基于Vue.js的IoT设备管理系统，提供设备管理、场景自动化、数据监控等核心功能。本文档将指导您在没有基础数据的情况下，从零开始测试所有核心功能。

### 🎯 核心功能模块
- **设备管理**: 设备类型定义、设备实例管理
- **场景管理**: 自动化场景创建和执行
- **场景设计器**: 可视化场景编辑工具
- **设备监控**: 实时状态监控和历史数据
- **数据分析**: 图表展示和统计分析
- **系统配置**: MQTT配置和系统设置
- **模拟器管理**: 设备模拟和测试

## 🚀 测试前准备

### 环境检查
1. 确保前端服务运行在 http://localhost:8083/
2. 确保后端服务正常运行（设备服务8081、场景服务8082）
3. 确保MQTT服务正常运行（端口1883）

### 浏览器要求
- 推荐使用Chrome、Firefox或Edge最新版本
- 开启开发者工具以便查看网络请求和错误信息

## 📝 详细测试步骤

### 1. 首页功能测试

#### 1.1 访问首页
1. 打开浏览器，访问 http://localhost:8083/
2. 验证页面正常加载，无JavaScript错误
3. 检查导航菜单是否完整显示

#### 1.2 导航测试
1. 点击左侧导航菜单各个选项
2. 验证页面路由跳转正常
3. 检查面包屑导航是否正确

### 2. 设备类型管理测试

#### 2.1 创建第一个设备类型
1. 点击导航菜单中的"设备类型管理"
2. 点击"新增设备类型"按钮
3. 填写设备类型信息：
   ```
   类型名称: 智能灯泡
   类型标识: smart_bulb
   描述: 可调光调色的智能LED灯泡
   分类: 照明设备
   ```

#### 2.2 添加设备属性
1. 在设备类型创建页面，添加属性：
   ```
   属性1:
   - 属性名: 开关状态
   - 标识符: power
   - 数据类型: 布尔型
   - 可读: 是
   - 可写: 是
   
   属性2:
   - 属性名: 亮度
   - 标识符: brightness
   - 数据类型: 整数
   - 取值范围: 0-100
   - 可读: 是
   - 可写: 是
   
   属性3:
   - 属性名: 颜色
   - 标识符: color
   - 数据类型: 字符串
   - 可读: 是
   - 可写: 是
   ```

#### 2.3 添加设备操作
1. 添加操作定义：
   ```
   操作1:
   - 操作名: 开灯
   - 标识符: turn_on
   - 描述: 打开灯泡
   
   操作2:
   - 操作名: 关灯
   - 标识符: turn_off
   - 描述: 关闭灯泡
   
   操作3:
   - 操作名: 设置亮度
   - 标识符: set_brightness
   - 参数: brightness (整数, 0-100)
   ```

#### 2.4 保存并验证
1. 点击"保存"按钮
2. 验证设备类型创建成功
3. 在设备类型列表中查看新创建的类型

### 3. 设备管理测试

#### 3.1 创建设备实例
1. 点击导航菜单中的"设备管理"
2. 点击"添加设备"按钮
3. 填写设备信息：
   ```
   设备名称: 客厅主灯
   设备ID: living_room_light_01
   设备类型: 智能灯泡 (选择刚创建的类型)
   位置: 客厅
   描述: 客厅中央吸顶灯
   ```

#### 3.2 批量创建更多设备
重复上述步骤，创建以下设备：
```
设备2:
- 名称: 卧室台灯
- ID: bedroom_lamp_01
- 类型: 智能灯泡
- 位置: 卧室

设备3:
- 名称: 厨房灯带
- ID: kitchen_strip_01
- 类型: 智能灯泡
- 位置: 厨房
```

#### 3.3 设备操作测试
1. 在设备列表中找到创建的设备
2. 点击"控制"按钮
3. 测试各种操作：
   - 开关控制
   - 亮度调节
   - 颜色设置

### 4. 场景管理测试

#### 4.1 创建简单场景
1. 点击导航菜单中的"场景管理"
2. 点击"新建场景"按钮
3. 填写场景信息：
   ```
   场景名称: 回家模式
   场景ID: home_arrival
   描述: 回家时自动开启客厅和玄关灯光
   状态: 启用
   ```

#### 4.2 配置触发条件
1. 在触发器部分，添加触发条件：
   ```
   触发器类型: 时间触发
   触发时间: 18:00
   重复: 每天
   ```

#### 4.3 配置执行动作
1. 在动作部分，添加执行动作：
   ```
   动作1:
   - 设备: 客厅主灯
   - 操作: 开灯
   - 参数: 亮度=80
   
   动作2:
   - 设备: 卧室台灯
   - 操作: 开灯
   - 参数: 亮度=50
   ```

#### 4.4 保存并测试场景
1. 点击"保存场景"
2. 在场景列表中找到创建的场景
3. 点击"执行"按钮测试场景
4. 验证设备状态是否按预期改变

### 5. 场景设计器测试

#### 5.1 可视化场景编辑
1. 点击导航菜单中的"场景设计器"
2. 点击"新建场景"或编辑现有场景
3. 使用拖拽方式添加组件：
   - 从左侧组件库拖拽"设备"组件到画布
   - 拖拽"条件判断"组件
   - 拖拽"延时"组件

#### 5.2 连接组件
1. 使用连线工具连接各个组件
2. 配置每个组件的参数
3. 创建一个复杂的自动化流程

#### 5.3 场景预览和保存
1. 点击"预览"按钮查看场景逻辑
2. 点击"保存"保存场景配置
3. 测试场景执行效果

### 6. 设备监控测试

#### 6.1 实时状态监控
1. 点击导航菜单中的"设备监控"
2. 查看设备状态卡片
3. 验证设备在线状态显示
4. 检查设备属性值更新

#### 6.2 历史数据查看

3. 调整时间范围
4. 验证数据图表正常显示

#### 6.3 告警信息
1. 查看告警列表
2. 测试告警确认功能
3. 验证告警状态更新

### 7. 数据分析测试

#### 7.1 统计图表
1. 点击导航菜单中的"数据分析"
2. 查看各类统计图表：
   - 设备状态分布饼图

#### 7.2 数据筛选
1. 使用时间范围筛选器
2. 按设备类型筛选
3. 按位置筛选
4. 验证图表数据更新

### 8. 系统配置测试

#### 8.1 MQTT配置
1. 点击导航菜单中的"系统配置"
2. 进入MQTT配置页面
3. 填写MQTT服务器信息：
   ```
   服务器地址: localhost
   端口: 1883
   用户名: (可选)
   密码: (可选)
   客户端ID: lowcode-platform
   ```

#### 8.2 系统设置
1. 配置系统基本信息
2. 设置数据保留策略
3. 配置备份设置
4. 保存配置并验证

### 9. 模拟器管理测试

#### 9.1 启动设备模拟器
1. 点击导航菜单中的"模拟器管理"
2. 查看可用的模拟器列表
3. 选择设备类型启动模拟器
4. 配置模拟器参数

#### 9.2 模拟数据生成
1. 启动数据模拟

## 🔧 常见问题和解决方案

### 问题1: 页面加载空白
**解决方案:**
1. 检查前端服务是否正常运行
2. 查看浏览器控制台错误信息
3. 确认API服务是否可访问

### 问题2: API请求失败
**解决方案:**
1. 检查后端服务状态
2. 验证API端点配置
3. 查看网络请求详情

### 问题3: 设备控制无响应
**解决方案:**
1. 检查MQTT服务状态
2. 验证设备模拟器是否运行
3. 确认设备ID配置正确

### 问题4: 数据不持久化
**解决方案:**
1. 当前使用H2内存数据库，重启后数据会丢失
2. 这是正常现象，可参考数据库升级方案文档
